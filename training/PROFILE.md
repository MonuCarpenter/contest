# CP Training — Learner Profile & Goal

This folder is a self-contained competitive-programming training system for the
learner. It is written so that ANY AI assistant (or human coach) can open these
files and continue guiding the learner without re-asking basics.

## Learner
- **Current rating:** 800 (Codeforces, approximate)
- **Platform focus:** Codeforces (primary), AtCoder (secondary)
- **Experience:** Beginner. Has CPbook4 (Competitive Programming 4, Halim) but
  finds it overwhelming — do NOT push the full book yet.
- **Start date:** 2026-07-13

## Ultimate Goal
Be able to solve **all Div2 problems (A–F)** in a Codeforces Div2 round.
This maps roughly to a **2100+ Codeforces rating** (Candidate Master+).

## Milestone map (by rating)
| Stage | Rating | Can solve in Div2 | Focus topics |
|-------|--------|-------------------|--------------|
| 1 | 800 → 1200 | A, B reliably | implementation, math, greedy, brute force, strings, sorting |
| 2 | 1200 → 1400 | B, attempt C | prefix sums, binary search, two pointers, 1D DP, BFS/DFS, combinatorics |
| 3 | 1400 → 1600 | C in contest | 2D DP, DSU, Dijkstra, sliding window, number theory |
| 4 | 1600 → 1900 | D regularly | trees (LCA/diameter), segtree/Fenwick, bitmask DP, game theory |
| 5 | 1900 → 2100+ | E/F | flows/matching, advanced DS, geometry, strong math |

## Current stage: STAGE 1 (800 → 1200)
The learner should NOT study later-stage topics yet. Learn techniques
"just in time" — only when a problem requires one.

## Resource rules
- CPbook4: IGNORE for now (return ~1400). If a topic is needed, read only the
  chapter summary + its STARRED problems.
- Primary practice: Codeforces problems rated 900–1100 (one step above learner).
- CSES / USACO Guide: later stages only.
- Overwhelm guard: never assign more than the weekly routine below.

See SYSTEM.md for the weekly routine, LOG.md for the problem tracker,
TODAY.md for the current day's checklist, HANDOFF.md for how to continue.
